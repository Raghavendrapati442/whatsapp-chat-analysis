# GroupDNA website starter

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run: `python -m pip install -r requirements.txt`
4. Run: `python -m streamlit run app.py`
5. Open the local URL shown in the terminal (usually http://localhost:8501).

Upload a WhatsApp-exported `.txt` file when the page opens.

Note: this starter includes message counts, participant leaderboard, activity by hour, top words, daily message volume, and CSV export. Response-time, silent-streak, and personality analysis from the notebook can be added later.
